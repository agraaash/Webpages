# Aashna Agrawal | AI & Product Portfolio

A clean, responsive portfolio showcasing five AI-powered prototypes and product experiments.

## View the portfolio

After enabling GitHub Pages for this repository, visit:

`https://agraaash.github.io/Webpages/ai-portfolio/`

## Projects included

- WordyFriends — English learning for children
- Microsoft Workforce Insights — AI workforce planning prototype
- HUL Shikhar — Kirana Trend AdStudio
- ISB MBA Workload Planner
- Interview Self-Awareness Coach

The site links to each public source repository and includes live demos where a URL has been provided.

## Publish with GitHub Pages

In the `agraaash/Webpages` repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. The portfolio is in the `ai-portfolio/` folder, so its URL will end in `/Webpages/ai-portfolio/`.
